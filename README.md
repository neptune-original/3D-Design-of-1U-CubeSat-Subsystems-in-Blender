# 3D Design of 1U CubeSat Subsystems in Blender

3D models of the main subsystems of a 1U CubeSat, designed in Blender. This work was created as a complementary addition to our final year project, **Design and Development of a Digital Twin of a 1U CubeSat**, to give the digital twin a more detailed and realistic visual representation of the satellite's hardware.

Each subsystem is modelled as a 3D plate of the CubeSat stack. The repository contains the editable Blender source files (`.blend`) and a short rotating preview clip (`.mp4`) for each design.

## Subsystems Modelled

A CubeSat is built from several cooperating subsystems. The following six were designed in this project:

- **Structure:** the CubeSat chassis, forming the physical frame that holds the rest of the stack.
- **Electrical Power System (EPS):** the power subsystem plate.
- **On-Board Computer (OBC):** the on-board computer plate.
- **Communication System:** the communication plate, including the dipole antennas.
- **Attitude Determination and Control System (ADCS):** the attitude determination and control plate.
- **Payload:** a camera, representing an Earth-observation satellite.

## Opening the Files

1. Download or clone this repository.
2. Open any `.blend` file in [Blender](https://www.blender.org/download/).
3. Orbit, zoom and inspect the model in the 3D viewport.
